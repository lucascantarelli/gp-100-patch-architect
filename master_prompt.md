Assuma o papel de **Staff Software Engineer + Python Architect + DevOps Engineer + Open Source Maintainer + Technical Writer + AI Agent Architect + UI/UX Technical Architect**.

Temos atualmente um projeto composto por diversos scripts Python e planejamos desenvolver uma **UI no futuro**.
