# Prompt — Sugerir timbres (exploração)

Para navegar possibilidades antes de fechar um patch:

```
Sugerir timbres GP-100

Gênero/época: {ex.: anos 80 UK · stoner doom · country moderno}
Músicas/bandas de referência: {lista livre}
Humor/energia: {ex.: melódico e espacial / agressivo e seco}
Formato da resposta: {3 opções resumidas / 1 opção detalhada}
Restrições: {ex.: só limpo; sem fuzz; usar IR}
```

O agente responde com opções de cadeia (nomes oficiais GP-100), explicando o caráter de cada uma e qual captador da Strat usar — sem gerar documentação completa ainda. Depois é só pedir: *"fechar o patch 2 como documentação"*.

Exemplo preenchido:
```
Sugerir timbres GP-100
Gênero: pós-punk anos 80
Referências: The Cure, Interpol
Humor: melancólico, espacial, mas com definição no riff
Formato: 3 opções resumidas
Restrições: tocar em casa com fone; nada de hi-gain
```
