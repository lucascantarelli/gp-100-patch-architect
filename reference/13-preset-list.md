# GP-100 — Presets de Fábrica e Drum Patterns

## Presets de fábrica (F01–F99)
A GP-100 vem com 99 presets de fábrica organizados por estilo (clean, blues, rock, metal, ambient, experimental, acústico). Eles servem de **referência de ponto de partida** — o agente pode citar um preset de fábrica como "parentesco" ao explicar uma escolha, mas os patches do projeto são sempre criados do zero nos slots de usuário.

Organização útil para o projeto:
- Faixa inicial (F01–F2x): cleans/leves (Twin, JC-120, acústico).
- Meio (F3x–F5x): blues/rock clássico (Bassman, AC30, JCM800, drives clássicos).
- Faixa alta (F6x–F8x): hard/metal (Mesa, ENGL, 5150).
- Final (F9x): experimentais (ambient, fuzz, wah).

> Não confie na lista exata de fábrica de cor: os slots variam com firmware. Sempre reconstrua o patch do zero com a `reference/` — é o propósito deste projeto.

## Uso no projeto
- Ao criar patch de estilo rítmico, sugerir drum + BPM para o músico testar (ex.: funk → Drum 45–48, 110 BPM).
- Metal/djent → Metro (padrões 94/97/99) para treinar sincronia com o delay Beat.
